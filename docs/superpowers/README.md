# Historical plans and specifications

The files under `docs/superpowers/plans/` and `docs/superpowers/specs/` are
immutable historical records of prior design and implementation work. Their
paths, commands, and snapshots describe the repository as it existed when each
record was written and are intentionally preserved.

For the current repository state, use the root `README.md` and the current task
records under `tasks/`. Those sources are authoritative for active paths,
commands, onboarding, and the V9-first runtime.
